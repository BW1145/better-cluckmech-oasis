# 鸡械绿洲跳过开屏 1.1.0

启动时跳过全部商标展示，直接进入原版加载与主菜单流程。

退出游戏，将完整包内容放到游戏根目录，与 `Cluckmech Oasis.exe` 放在一起。模组位于 `BepInEx/patchers/CluckmechSkipSplash.dll`，也包含在“更好的鸡械绿洲”整合包中。更新时保留自己的配置。

整合包主菜单的模组设置提供独立开关，下次启动生效。单独使用时，可在 `BepInEx/config/billy.cluckmech.coop.cfg` 的 `[Modules]` 中设置 `SkipSplash = true` 或 `SkipSplash = false`。首次使用默认开启。
