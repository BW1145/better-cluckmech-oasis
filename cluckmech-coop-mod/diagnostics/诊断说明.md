# 联机模组运行诊断

本组件观察“强化远征与队友转交”的实际运行状态，记录到游戏目录的 `BepInEx\LogOutput.log`，每条诊断记录以 `[DIAG]` 开头。

## 使用

1. 将压缩包里的 `BepInEx` 文件夹合并到游戏安装目录。新增文件是 `BepInEx\plugins\CluckmechCoop\CluckmechCoopDiagnostics.dll`。
2. 双方启动游戏，创建并加入双人房间。
3. 进入战斗准备界面，由房主勾选原版挑战选项，再进入战斗并清完一个普通波次。
4. 使用双方的 `BepInEx\LogOutput.log` 核对强化及按钮失效环节。本机日志可以直接由当前排查任务读取。

若安装时游戏已在运行，下一次启动才会加载诊断组件。

## 记录内容

- 原模组版本、实际生效的补丁数量及方法清单。
- 模组及界面组件是否活动，界面画布是否生成。
- 当前主机或客户端身份、地图状态、准备背包是否存在、转交条件的实际结果。
- 勾选的挑战状态、刷怪器保存的挑战状态、当前波次、出怪组、Boss 波标记及追加轮标记。
- 挑战同步消息、模组同步消息类型、敌人数量及生命和攻击样本。

当前组件记录启动帧数、所属场景、销毁回调及原玩法补丁是否仍在。对两个单参数托管销毁入口注册只记录的观察补丁，记录以加载器对象为目标的调用者，正常销毁继续执行。
