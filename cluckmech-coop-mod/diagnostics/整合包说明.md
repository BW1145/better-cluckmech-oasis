# 强化远征与队友转交：运行诊断版

此安装包包含当前模组 0.1.0、运行诊断组件 1.0.0 和 BepInEx 加载器。双方使用同一个安装包即可。

## 安装和排查

1. 双方退出游戏。
2. 将压缩包中的文件复制到各自的鸡械绿洲安装目录，与 `Cluckmech Oasis.exe` 放在一起，合并文件夹并覆盖同名文件。
3. 双方启动游戏，创建并加入双人房间。
4. 在准备界面，由房主勾选原版挑战选项，进入战斗并清完一个普通波次。
5. 诊断记录自动写入各自游戏目录的 `BepInEx\LogOutput.log`，以 `[DIAG]` 开头。本机日志可以由当前排查任务直接读取；房主日志用于核对敌人生成和强化逻辑。

游戏目录由 `CLUCKMECH_GAME_DIR` 环境变量或脚本的 `-GameDir` 参数指定。

## 诊断范围

记录实际生效的补丁清单、模组和界面是否活动、转交按钮的显示条件、挑战状态、刷怪器当前波次和追加轮标记，以及敌人生命与攻击样本。

整合包沿用当前发生故障的玩法代码，以采集同一版本的运行证据。诊断组件只读取状态；此包用于排查，并非已通过实战验证的修复版。

模组文件与诊断文件分别位于 `BepInEx\plugins\CluckmechCoop\CluckmechCoop.dll`、`BepInEx\plugins\CluckmechCoop\CluckmechCoopDiagnostics.dll`，安装包已包含两者。
