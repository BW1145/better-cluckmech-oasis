# 战备客机命中显示回归

本套件覆盖 PR #1 遗漏的战备伤害显示通路，与 `CoopRepairLimits` 共用既有显示替身。无需原版 DLL 或公开游戏资源。

```sh
python3 cluckmech-coop-mod/tests/StratagemHitDisplay/Prepare.py
dotnet run --project cluckmech-coop-mod/tests/StratagemHitDisplay/StratagemHitDisplayTests.csproj -c Release
```

## 实现边界

- `StratagemDamage.Hit` 在原有伤害调用外增加显示捕获作用域；地雷、火力网、轨道激光、飞鹰、护卫犬和矿物命中共用这个入口。伤害包、房主结算及状态添加保持原样。
- 状态持续伤害沿原版已有求和循环观察来源，不再遍历一次状态列表。原求和值保持不变；只回传战备来源在原版实际显示值中的份额，普通来源的本地数字不重复转发。弱来源标记不强持有已销毁的攻击者。
- 共用一个有数据才运行的发送任务，最多256条即发送；小批量最多等待0.1秒真实时间。复用现有 Effect/Data 结果通道，只发客机，不给每台战备建立独立任务。原版死亡入口前先发送待发的击杀数字。
- 接收在异界角色开关判断之前辨认带 STRA 标记的战备结果；未启用异界时不要求 OtherworldUnit。普通角色观看空间使用已有原版玩家缓存。其他角色消息和协议字段顺序保持不变。
- 客机继续使用原版数字/命中特效入口；初始化等待沿用512条、1秒上限。无额外全场扫描，空闲没有发送任务。跨空间反伤不改。

## 检查范围

`Prepare.py` 抽取完整的生产构造函数、Hit、State、SendDisplay及接收门控；并核对各战备实际入口接线。测试直接编译显示捕获、分批、回放和状态求和转译生产文件。Unity对象、房主原生受伤执行、网络、相机和渲染由替身提供；测试检查调用与状态，不把它们视为游戏画面或FPS实测。

涵盖主/客/单机、异界开关、普通/暴击/无敌/保护、矿物、600命中分批、连续激光节奏、清场与战斗标识、死亡前发送、混合来源灼烧/毒/流血颜色、嵌套角色技能与战备、普通角色空间筛选、延迟初始化、无伤害/状态/统计副作用，以及转译位置变化拒绝。
