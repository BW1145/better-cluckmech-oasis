# 战备美术与声音

0.5.2使用一份按需加载的运行图集`stratagem-v2.png`及对应矩形、枢轴、像素密度和炮口元数据，含103个切片。33项专属强化各有对应部件图标；背包和详情图采用原版50像素画布、25像素/世界单位，主体最大38像素。机体部件按32像素/世界单位导入。放置预览按实际部件尺寸和安装位置合成，以64像素/世界单位及地面原点导入。全部采用最近邻采样。

## 动作与显示

`StratagemRig`驱动固定底座、旋转座、炮管轴向后坐、瓣片、能源塔及无人机的独立姿态。`StratagemEffects`组合投送、尾迹、火核、火球、碎片、烟尘和弹坑。电场、瓦斯及护罩采用一次建立的像素网格：EMS内部12%、边缘40%，三组分段电弧交替闪动并配合内圈脉冲；护罩内部10%、蜂窝18%、边缘40%。地面效果位于单位下方，重叠电场降低视觉亮度。所有动作使用游戏时间。

`tests/Rig`直接运行生产动作代码，导出姿态后用`RenderPreview.py`进行离线合成。`ValidateStratagemAssets.py`检查精确切片、33张图标、8方向部件、肖像留白和音频。

## 音效

运行包含四份Vorbis：380爆炸、500kg爆炸、轨道激光启动和持续循环。`MakeStratagemSounds.py`保存合成参数，运行使用原版Master Audio音效总线，音量随玩家与声源距离变化。每条轨道激光独立持有和停止自己的循环声音。
