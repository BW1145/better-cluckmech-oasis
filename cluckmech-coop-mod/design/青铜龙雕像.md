# 青铜龙雕像

B级特殊鸡械，放置消耗3动力、冷却35秒、初始冷却2秒，基础生命350、格挡0、抗性0，基础强化上限4次。

每10秒生产1金币，不攻击敌人。商店与关卡奖励按原版B级规则提供，在工匠处强化。主菜单提供独立模块开关，本局采用房主设置。

造型复用黄金龙雕像的完整轮廓、图标、放置预览和落地烟雾；金色部位替换为青铜色，保留像素、透明留白、锚点与尺寸。调色结果在插件生命周期缓存，原版资源保持独立。

## 强化池

共14项，每项一个候选条目，沿用原版等概率三选一及唯一强化过滤。

| 专属强化 | 效果 |
|---|---|
| 双孔铸模 | 每次生产的金币增加至2枚，唯一 |
| 精密传动 | 生产间隔缩短至6秒，唯一 |
| 积少成多 | 每完成5次生产，额外生产2金币，唯一 |
| 开库见财 | 放置时立即生产3金币，唯一 |

额外金币不计为生产次数。每座雕像独立计时。基础持续收益6金币／分钟，前三项专属齐全后24金币／分钟，放置收益另计。

| 原版强化 | 效果 |
|---|---|
| 资源利用 | 放置时20%概率返还本次动力，多次获取独立判定 |
| 节能 | 放置时掉落1动力 |
| 产能升级 | 每45秒掉落1动力 |
| 资源转化 | 放置时按动力费用生成金币，剩余动力大于10时额外生成6金币，唯一 |
| 工资回收 | 被摧毁时掉落2动力 |
| 坚固 | 生命增加200，格挡增加5 |
| 简易回复核心 | 每秒回复生命增加8 |
| 乌龟核心 | 生命增加600，每秒回复生命增加2 |
| 零度汽水 | 每5秒生成临时冰面，使经过的敌人脚滑3秒，唯一 |
| 紧急支援 | 放置时生成3只临时特种兔，持续15秒 |

原版强化使用游戏实际数据与既有叠加规则。乌龟核心的实际资源为600生命。

## 生产与联机

使用游戏时间计时，暂停与倍速沿用游戏规则。房主或单机执行生产，主战场金币按批同步生成，拾取与结算采用原版流程。神威空间金币沿用空间掉落通道。空间阵地快照保存生产剩余时间、五次生产计数及放置奖励状态。
