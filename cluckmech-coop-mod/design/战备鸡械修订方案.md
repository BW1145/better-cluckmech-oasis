# 战备鸡械修订方案

版本0.5.11。实施范围为七台战备鸡械的动画、特效、图标、强化及音效，强化图鉴，工匠刷新券，肚子鳄与水母骑士的吞噬选择，以及矿洞音乐曲库。

## 1. 七台动画

沿用已认可的装备造型，机体与放置预览按原尺寸75%显示。每台按结构划分固定件、活动件、附属物和效果；同一部件各帧共用画布、比例和挂点。帧序按一次动作的起点、运动、停顿和收束制作。部署、发射与伤害触发按现有战斗时间衔接。

|---|---|---|

迫击炮转向与开火共享对应方向的炮管外观；待机姿态接入发射动作后，底座落点、旋转座轴心、炮口位置连续。护卫犬在返航、停靠和起飞中，每个阶段只由一份无人机外观承担显示。

### 1.1 特效与层级

- 地面层：弹坑、灼痕、持续燃烧区域、EMS范围与瓦斯纹理；与原版地面显示规则对齐。
- 单位层：本体、敌人、基地车，持续地面效果下仍保持轮廓清晰。
- 短暂效果：爆炸、土块、枪口火花与护盾受击波纹，按各自位置和时间显示。
- 轨道光柱：显示从上方贯穿的主体，落地亮核绑定伤害区域，外围光晕控制透明度；伤害数字和血条清晰可见。
- EMS使用透明电弧主体，保留源图RGB；按明亮电弧边界标定实际半径。多个电场重叠时控制可见亮度，实际范围、计时和状态分别计算。
- 护罩使用一份能量膜主体，内膜像素透明度约2.5%至12.5%，边缘约22%至67%；受击使用实际撞击位置的局部补片，保留明亮接触点。
- 烟尘随时间减少密度，弹坑与灼痕淡出。持续视觉对象随对应效果结束回收。

### 1.2 资源制作与检查

1. 每个部件使用一致比例、同一透视与固定锚点；活动件分别绘制，用旋转、位移和关键帧组合动作。
2. 图集按逐帧实际边界整理，帧间留透明间隔，光晕包含在各自切片内。固定件不随活动件扩大画布而改变位置。
3. 离线完整播放七台部署、待机、攻击、结束和损毁状态；可转向机体检查八个方向与状态交接，按战斗显示尺寸查看。
4. 检查多个EMS电场、连续380落弹、护盾与怪物重叠，以及多只护卫犬返航时的可读性。
5. 时间使用游戏时间。攻速影响的发射与动画保持衔接，二倍速同时影响动画与战斗；强制结束时清理该效果的显示。

## 3. 强化图鉴、存档和图标

- 完整图鉴读取完整强化池；三选一在自己的候选列表中处理唯一、互斥和已获得项。
- 旧存档中的词条编号继续可读取；移出新抽取池的旧强化保留原有作用。合并强化与对应旧效果重合时按最终数值作用一次。
- 尤其保留旧EMS已获得的控制与瓦斯组合；新抽取按本方案的分支规则执行。
- 背包、商店、详情图标独立制作，主体约占框内宽高的64%，按视觉中心对齐；放置预览匹配战斗轮廓。
- 专属强化制作对应部件图标：弹链、地雷弹头、弹舱、准星、供能装置、镜片、电容、线圈、散热器等。各强化保留可区分的形状与色彩。
- 图标不改变战斗机体的大小，稀有度边框及原版界面布局继续由现有界面处理。

## 4. 音效

- 380：只在炮弹实际命中时播放爆炸声，跟随命中位置，并限制多发重叠的总音量。
- 轨道激光：启动声、照射期间循环声、结束时停止循环；多个激光控制混音与重叠。
- 飞鹰500kg：保留一次命中爆炸声，与伤害和火球出现时间一致。
- 上述三种声音按位置与距离调整音量，使用原版音效音量设置。
- 地雷播撒器、地雷、EMS、护盾发生器与激光护卫犬使用静音的新增表现。通用部署音效停用。

## 5. 刷新券与吞噬

### 工匠刷新券

- 每家商店每人限购一次，30金币获得1次额外工匠刷新。
- 每个维修节点每位玩家固定获得1次额外刷新，维修原有收益继续保留；基地满血时仍可领取节点赠券。
- 在完成维修节点操作时发放，按本局地图节点和玩家记录领取状态。重开窗口、继续存档和联机重复消息沿用领取记录。
- 免费次数先消耗，再消耗券；未使用余额本局继续保留。
- 当前存档已经积累的余额保留，后续购买按上述规则获得。

### 肚子鳄与水母骑士

- 同时覆盖两个角色的目标提示、发动选择和联机目标同步。
- 使用原版当前吞噬范围及天赋修正；鼠标指向范围内合法的可吞对象时优先选择它。
- 鼠标指向合法可吞对象但对象在范围外时，保留目标提示的范围反馈，本次吞噬按原版失败处理；鼠标位于空地或非吞噬对象时，使用角色最近的合法目标。
- 若当前吞噬数量超过1，鼠标目标排第一，其余按角色距离选择，数量由原版与天赋决定。
- 发动时确定实际目标，联机同步这些单位身份。发动后目标失效时结束对该目标的操作。
- 提示标记展示将被吞噬的首个目标。肚子鳄的假吞与攻击效果、水母骑士的格挡与万剑合一、冷却和原版吞噬收益分别沿用各自规则。

## 6. 矿洞音乐

矿洞普通战斗曲库由原版矿洞曲、《岩窟快车》《矿脉引擎》组成，在原版换曲时机从三个实际曲目中等概率选取，每首1/3。各曲共用原版音乐音量设置与当前固定增益校准。

《矿脉引擎》时长120秒、128 BPM；扬琴主题、吉他、金属敲击与低音推进。OGG检查为−22.04 LUFS、真峰值−5.46 dBTP，解码后循环边界幅度差约0.00175。

## 7. 实施检查与交付

1. 逐台动画、图标与特效完成后，离线按战斗显示尺寸检查所有状态和方向衔接，再接入原版事件和当前战斗时间。
2. 核对33项新抽取强化的属性、互斥和组合，完整图鉴、旧编号读取及合并效果执行。
3. 检查两人吞噬同一目标的结果一致、维修赠券按玩家和节点领取、存档继续保留余额，以及矿洞三曲概率。
4. 相关代码和资源检查完成后，构建完整安装包，按已有约定安装并发布。实机测试由用户进行。

## 当前基础参数与布设

- 地雷播撒器、护盾发生器和激光护卫犬基础费用均为3动力。
- 护盾发生器5000生命、15格挡，护罩半径4.5；扩域线圈半径5.5，容量为本体最大生命的40%，备用电容为55%。
- 地雷使用本关地面导航与建筑碰撞检查；所有播撒器共享0.6格地雷间距，优先在3.2格范围内的地面敌人脚下布设，没有合法空位时不生成。
- 护卫犬每个固定基座对应一架无人机，允许多个基座；无人机跟随所属角色作战，过热回到所属基座充能。
- 顶部介绍沿用原版的强化方向、分条说明和关键词颜色，直接显示呼叫等待、存在时间、触发限制及结束方式。

- 激光接触点混用原版命中火花，EMS内部混用感电粒子，燃烧地面使用灼痕和原版灼烧粒子；爆炸主体帧包含火球、土块与消散烟尘。粒子与逐帧纹理共用游戏时间，使用单位排序层；持续电场和地面残留位于单位下面。每个粒子系统上限16～24，持续效果仅创建一次。
