# 异界角色 0.6.1

主菜单“异界角色”模块提供佩丽卡与宇智波带土。原版十二个角色位置保留，新增角色位于顶排右侧。每人开局选择一种初始天赋，本局成长从四项通用和对应路线两项中选择，各项为唯一成长；获得全部六项后沿用原版通用候选。

## 基础参数

| 参数 | 佩丽卡 | 宇智波带土 |
|---|---:|---:|
| 生命 | 600 | 750 |
| 生命再生 | 5 | 5 |
| 攻击力 | 50 | 80 |
| 每秒普攻 | 4 | 2.5 |
| 射程 | 6格 | 5格 |
| 移速 | 4 | 4.5 |
| 暴击率 | 10% | 10% |
| 面板暴击伤害 | 200% | 200% |
| 初始鸡械 | 电鳗塔1台 | 火鸡1台 |

佩丽卡普攻使用电磁弹。基础右键为半径1.8格、攻击力×12的雷击，附加5秒原版麻痹，冷却8秒。协议ε·70.41K升级为半径3.5格、攻击力×80的轨道残骸轰击，裸值4000伤害，基础冷却8秒，附加5秒麻痹，并继承初始天赋及其他右键成长。

带土普攻投掷苦无。按下右键立即虚化1.5秒、移速×1.5，基础冷却10秒；持续按住0.25秒向移动方向冲刺3格（站定时沿最后移动方向，尚未移动时向下），耗时0.35秒，吸入沿途近身敌人与自己。在空间内按右键返回；虚化状态结束时复算速度和无敌，保留其他来源的属性加成。

## 神威空间

- 每位带土拥有36×24格独立场地，位于主地图边界外；空间之间、空间与主战场保持至少64格距离。使用独立地面与空中导航。
- 冲刺按单位实际受击轮廓扫掠并去重。Boss本体与必要部件共同转移，保留内部关联。
- 临时囚禁基础5秒，敌人到期回到各自被吸入的位置。时空间延展将时间提高至8秒。带土返回本次冲刺终点，受阻时就近选择合法位置。
- 永久收容作用于普通敌人，将其移出原战场清场计数；实际死亡时结算击杀和奖励。精英与Boss按临时规则释放。
- 进入结算后结束新吸入，返回继续可用，已有临时释放计时继续推进。
- 房主执行空间内部战斗，玩家离开后阵地继续攻击。每位玩家接收自己的私有空间实体，共同战场保留必要玩家、Boss和收益引用。
- 目标、仇恨、移动、光环、弹丸、伤害与拾取按所属空间隔离。掉落保留稳定身份，所有者进入同空间后按原版规则领取。
- 常驻阵地、永久囚犯、未领取掉落在本局跨关保留；地图、商店及退出时保存剩余时间。开始新局建立新的角色与空间记录。
- 快照包含定义、强化、难度来源、生命、状态、巢穴子体与计时，以及战备在途攻击、地雷、护盾、无人机热量和停靠状态。角色快照使用独立存档键，实体变化沿用原版同步。
- 虚实转移赠送的虚化承接一次完整返回动作；喷火与反击统一在该段虚化结束时结算。
